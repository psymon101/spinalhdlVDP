# ADR-005 — Amiga scope is OCS/ECS; AGA is deferred

## Status

Accepted.

## Decision

The initial Amiga visual adapter supports OCS/ECS features only. AGA, HAM8,
eight bitplanes, AGA palette/fetch/sprite behavior, and AGA timing are excluded.
